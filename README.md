# Carb-ulator
This project is my app Carb-ulator, which I made in order to help people calculate their insulin shot for meals using their total carbs, blood sugar, and unit amount.

To run the project, you need to:
1. Go to MIT app inventor  Link: https://appinventor.mit.edu/
2. Sign in with a google account
3. Click on projects on the top right corner
4. Select Import project (.aia) from my computer
5. Choose CARBULATOR.aia
